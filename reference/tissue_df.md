# Example boxing and judo injury counts by tissue/pathology type

An example dataset for
[`plot_sunburst()`](https://bnqcasimiro.github.io/spinviz/reference/plot_sunburst.md):
the standard
[injury_categories](https://bnqcasimiro.github.io/spinviz/reference/injury_categories.md)
taxonomy with two columns of (fictional) injury counts attached.

## Usage

``` r
tissue_df
```

## Format

A data frame with 25 rows and 4 columns:

- tissue_type:

  Tissue type, e.g. "Bone", "Nervous".

- pathology_type:

  Pathology type, e.g. "Fracture", "Tendon rupture".

- boxing:

  Number of recorded boxing injuries for that pathology.

- judo:

  Number of recorded judo injuries for that pathology.

## Details

Row order matches
[injury_categories](https://bnqcasimiro.github.io/spinviz/reference/injury_categories.md),
so the counts can be reused with other taxonomies built on the same
ordering.

## See also

[injury_categories](https://bnqcasimiro.github.io/spinviz/reference/injury_categories.md)
for the taxonomy without counts,
[`plot_sunburst()`](https://bnqcasimiro.github.io/spinviz/reference/plot_sunburst.md)
to plot this dataset, and
[body_df](https://bnqcasimiro.github.io/spinviz/reference/body_df.md)
for the equivalent example dataset for
[`plot_heatmap()`](https://bnqcasimiro.github.io/spinviz/reference/plot_heatmap.md).
